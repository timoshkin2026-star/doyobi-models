# Изоляция данных пользователей

## Что было исправлено

Теперь каждый пользователь видит только свои данные. Все пользовательские данные привязаны к `userId`.

## Данные, привязанные к пользователю:

### ✅ Донаты и подарки
- История донатов (`donationHistory`)
- История подарков (`donationHistory`)
- Платные сообщения (`donationHistory`)
- Каждая запись содержит `userId`

### ✅ Подписки
- Бесплатные подписки (`subscriptions`)
- Premium подписки (`premiumSubscriptions`)
- Каждая подписка содержит `userId`

### ✅ Бронирования
- Все бронирования (`bookings`)
- Фильтруются по `clientId` (который равен `userId`)

### ✅ История просмотров
- История просмотров моделей (`viewHistory`)
- Каждая запись содержит `userId`
- Ограничение: 50 записей на пользователя

## Как это работает

1. **При сохранении данных**: Добавляется `userId` текущего пользователя
2. **При загрузке данных**: Фильтруются только записи с `userId` текущего пользователя
3. **При удалении данных**: Удаляются только записи текущего пользователя

## Примеры

### Донаты
```javascript
{
  userId: 123456,
  type: 'donate',
  modelId: 1,
  modelName: 'Анастасия',
  amount: 1000,
  message: 'Спасибо!',
  date: '2024-01-15T10:30:00.000Z'
}
```

### Подписки
```javascript
{
  userId: 123456,
  id: 1,
  name: 'Анастасия',
  image: '...',
  category: 'Fashion',
  subscribedAt: '2024-01-15T10:30:00.000Z'
}
```

### История
```javascript
{
  userId: 123456,
  id: 1,
  name: 'Анастасия',
  age: 24,
  category: 'Fashion',
  price: 8000,
  rating: 4.9,
  reviews: 127,
  image: '...',
  status: 'online',
  viewedAt: '2024-01-15T10:30:00.000Z'
}
```

## Тестирование

Чтобы проверить изоляцию данных:

1. Создайте первый аккаунт (например, модель)
2. Отправьте донаты, подпишитесь на модели, забронируйте встречи
3. Выйдите из аккаунта
4. Создайте второй аккаунт (например, клиент)
5. Проверьте, что история первого аккаунта не видна
6. Отправьте свои донаты и подписки
7. Вернитесь в первый аккаунт - должны быть видны только его данные

## Примечание

**Избранное** (`favorites`) остается глобальным для всех пользователей на одном устройстве. Это сделано для упрощения, так как избранное используется для отображения сердечек на карточках моделей и не является критичными данными.

Если нужно сделать избранное тоже привязанным к пользователю, нужно изменить структуру с массива ID на массив объектов с userId.
