# Дойоби - Каталог моделей

Платформа для поиска и бронирования профессиональных моделей.

## Возможности

- 📸 Каталог моделей с фильтрами
- 💬 Система сообщений
- 👤 Личные профили (клиенты и модели)
- 📊 Панель управления для моделей
- ⭐ Рейтинги и отзывы
- 💎 Система донатов
- 📅 Бронирование съемок

## Технологии

- HTML5, CSS3, JavaScript
- LocalStorage для хранения данных
- Responsive дизайн

## Запуск локально

1. Откройте `index.html` в браузере
2. Или используйте локальный сервер:
   ```bash
   npx serve
   ```

Проект готов к деплою на Vercel, Netlify или GitHub Pages.
